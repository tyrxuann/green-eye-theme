# 实机核对清单（两款主题通用）

自动校验已经把**静态可查**的部分全部关闭（六条对账规则 + 撞色 + 调色板消费 + 产物新鲜度，
见 [`build/ref/verification.md`](build/ref/verification.md)）。
但下面这些屏**渲染管线结构上照不到** —— 之前两个真 bug（错误波浪线变成实线下划线、
Javadoc `@param` 下划线消失）就是这么漏掉的。装好后请按这张表扫一遍。

## 0. 自动预检

先跑一遍静态预检，排除"没装上 / 版本不对 / 字体缺失"这类问题：

```bash
python3 green_eye.py doctor
```

它不会启动 IDE，但会检查 palette、jar、`.icls`、VSIX、字体、IntelliJ 配置目录、
插件版本与 `disabled_plugins.txt`。通过后再做下面的目视项。

## 0.1 先确认装上了

- [ ] `Settings → Appearance & Behavior → Appearance → Theme` 里有**两款**：
      **Green Eye Dark 松林** 与 **Green Eye Mineral 矿彩**
- [ ] `Settings → Editor → Color Scheme` 下拉里也有这两套内置方案
- [ ] 随便打开一个 Java 文件，底色是墨绿、正文是暖白（两款底色相同 `#1F3027`）
- [ ] 切换两款主题，确认它们是**两套不同的语言**（松林=橙关键字/紫常量/绿字符串；
      矿彩=金黄关键字/赭石常量/玫瑰注解/冰青字符串/紫晶数字/玉青函数），而不是同一套的深浅差

## 1. 装饰线是否真的画出来了（重点：这两个曾经整类丢失）

- [ ] **错误/警告是波浪线**，不是实线下划线（故意写一行 `int x = "a";` 看红色波浪）
- [ ] **Javadoc 的 `@param` / `@return` 有下划线**（官方是绿色+下划线）
- [ ] **光标停在某个变量上**，该变量所有出现处是否有下划线（读取态）
- [ ] 给变量**赋值**时光标停在左边变量上，下划线颜色应与读取态不同
- [ ] `@Override`（橄榄）与 `@param`（薄荷绿）**不同色**
- [ ] `@Deprecated` 的方法名是**删除线**
- [ ] 超链接可点、已访问过的链接颜色有变化

## 2. 调试器（之前完全没覆盖）

- [ ] 打断点 → **断点行整行有底色**（不是只有 gutter 圆点）
- [ ] 启动调试 → **当前执行行有明显底色**（深蓝）
- [ ] 打开调用栈面板 → **非栈顶帧有底色**，与栈顶可区分
- [ ] 变量表里改过的值（重新赋值的变量）下划线是中性灰

## 2.5 「矿彩」专属（原创设计，需要你判断是否舒服）

- [ ] 关键字（金黄）与 TODO（芥黄）在**同一屏里能不能分开**
      —— 这两个都在暖黄区，是这套设计最紧的一处（判据要求 ΔE ≥ 12）
- [ ] `@Override`（玫瑰）与常量/字段（赭石）是否区分得开
- [ ] 函数（玉青 S50）与数字（紫晶）是否区分得开
- [ ] 查找命中是**琥珀色**（像荧光笔），与选中的**同相深绿**是两种信号 —— 这个设计你接受吗
- [ ] 注释是**冷石色**（不是松林那种暖灰），与正文的暖墨分层是否自然
- [ ] 整体观感：是"矿物/大地色系"还是"换了一组色相的彩虹"？（请直说，这是我设计时最担心的）

## 3. diff / VCS

- [ ] 打开一次改动 → 新增行绿、删除行红、修改行蓝，**三者互不混淆**
- [ ] 合并冲突文件 → 冲突标记是**红**的（不是琥珀色）
- [ ] 删除一堆文件 → 文件列表**不是满屏红**（已删除项是中性灰）
- [ ] 已复制/已重命名/已修改三种状态**颜色不同**

## 4. inlay hints 与参数提示

- [ ] `Ctrl+Space` 补全弹窗：底色比编辑器亮、**有 1px 描边**、选中行是高亮带
- [ ] 参数名内联提示（inlay hints）有**芯片底色**，不是直接压在代码上
- [ ] 当前正在填的那个参数提示**前景更亮**
- [ ] 提示芯片落在当前行 / 查找命中 / diff 新增行上时，**边界还看得清**
       （这是已知最紧的一处：如果发糊，告诉我）

## 5. 编辑器状态色（同屏共现时是否互撞）

- [ ] 选中一块代码是**青色**高亮；`Ctrl+F` 查找命中是**绿色**，且两者不同
- [ ] 当前匹配（`Enter` 跳到的那个）与其它匹配**底色有区分**
- [ ] 当前行有极淡的通栏高亮，但**不像脏斑**
- [ ] 括号匹配有底色/描边
- [ ] 多光标同时编辑时，各处光标与选区都看得清
- [ ] 折叠一段代码 → 折叠提示**有底色**

## 6. 主观项（只有一个，需要你定）

- [ ] `IDENTIFIER_UNDER_CARET`（光标停在标识符上）的底色目前是**偏蓝灰 `#3E4A50`**
      —— 官方是中性 `#373b39`。如果实机上觉得发浑/发脏，告诉我，我换成绿灰 `#2A4238`。

## 7. 长时间观感

- [ ] 连续滚动真实项目代码 10 分钟，眼睛有没有"跳"或"发闷"的地方
- [ ] 字符串（绿）、数字（青）、函数（蓝）、常量（紫）在同一屏里是否**分得开但不吵**
- [ ] 状态栏 / 左侧项目树 / 终端 是否与编辑器**同一套色感**

## 发现问题的回报方式

把屏幕截图 + 大概位置发我，或直接说"哪一行/哪个面板、什么颜色不对"。
配色改一处、跑一次 `green_eye.py build`（会自动重出所有预览图并跑完整套验收），
然后可以立刻对着新图确认。
